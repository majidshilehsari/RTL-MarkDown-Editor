# RTL Markdown Editor (ویرایشگر مارک‌داون راست‌چین)

یک ویرایشگر سریع و سادهٔ مارک‌داون **فارسی/راست‌چین** که با **Next.js** ساخته شده است.

مشکل اصلی که این ابزار حل می‌کند: هوش مصنوعی‌ها معمولاً **چپ‌به‌راست** می‌نویسند و متن فارسی
(حروف، علائم و ترتیب پرانتزها) را خراب می‌کنند.

## امکانات

- **پنل دوتکهٔ راست‌چین**: سمت راست ویرایش، سمت چپ پیش‌نمایش زنده
- **نوار ابزار کامل**: تیترها، بولد/ایتالیک/خط‌خورده، کد، لیست، نقل‌قول، لینک، تصویر، خط جداکننده
- **ساخت جدول** و **تبدیل CSV/TSV به جدول**
- **دکمهٔ «اصلاح چپ‌به‌راست»**:
  - حذف نویسه‌های کنترل دوجهته (LRM/RLM/LRE/PDF و...)
  - یکسان‌سازی حروف عربی به فارسی (ي→ی، ك→ک و...)
  - اصلاح علائم و پرانتز/کروشه‌های وارونه
  - تبدیل ارقام عربی به فارسی و نرمال‌سازی نیم‌فاصله (ZWNJ)
- **پاک‌سازی خودکار** متن چسبانده‌شده
- **بسته‌بندی RTL هنگام کپی** (نشانه‌های RLI/PDI) برای نمایش صحیح متن مخلوط در اپ‌های چت
- ذخیره خودکار در مرورگر، تم روشن/تاریک، ایموجی، تنظیم قلم و فاصله خطوط، اندازهٔ قابل‌تغییر پنل‌ها

## اجرای محلی

```bash
npm install
npm run dev
```

سپس `http://localhost:3000` را باز کنید.

## اسکریپت‌ها

| دستور | توضیح |
| --- | --- |
| `npm run dev` | سرور توسعه |
| `npm run build` | ساخت نسخهٔ تولید |
| `npm run start` | اجرای نسخهٔ ساخته‌شده |

## ساختار

```
app/         صفحه‌ها و کامپوننت Next.js
app/Editor.jsx   کامپوننت اصلی ویرایشگر
lib/bidi.js      منطق اصلاح چپ‌به‌راست و نرمال‌سازی فارسی
```
